# Mermaid diagrams

The Mermaid diagrams for ICUM-SIM live in:

- [docs/system-diagrams.md](../system-diagrams.md)

That file uses Markdown fenced Mermaid blocks (```mermaid), which should render in VS Code’s built-in Markdown preview.

## How to view

1. Open [docs/system-diagrams.md](../system-diagrams.md)
2. Run **“Markdown: Open Preview”** (or **“Open Preview to the Side”**)

## Troubleshooting

- If you only see code blocks, ensure Mermaid rendering is enabled in VS Code settings:
  - `markdown.mermaid.enabled`: `true`
- If you’re viewing on GitHub, Mermaid should render in the web UI as well.
